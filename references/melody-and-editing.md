# 멜로디 맞춤과 국소 교정

음절·프레이즈 제약, 멜로디 맞춤, 도치·압축·부분 퇴고 요청에 사용한다. 공통 작업 기준과 제외 조건은 [SKILL.md](../SKILL.md)를 따른다.

## 1. 자료에 맞춰 작업 범위를 정한다

| 받은 자료 | 할 수 있는 작업 | 확정하지 않을 것 |
|---|---|---|
| 가사만 | 표기 음절 수, 의미 단위, 예상 발음, 쉼 후보와 발음 충돌 점검 | 실제 박 위치·호흡 가능 시간·가창 적합성 |
| BPM·박자표 | 주어진 속도·마디 조건을 참고해 밀도와 분절 후보 제안 | 음표 수, 음절별 시작·지속, 강박에 놓일 단어 |
| 가창 슬롯·프레이즈 패턴 | 지정된 단위에 맞춰 발화 음절 또는 표기 블록을 대응 | 슬롯 수만으로 음높이·길이·쉼을 추정하지 않음 |
| 악보·MIDI·가이드 음원 | 실제로 읽거나 분석한 구간의 시작·지속·쉼·구절 경계와 가사를 대조 | 파일을 받았다는 이유로 청취·채보·실가창 검증을 완료했다고 하지 않음 |

먼저 사용자가 말한 `8음절`이 **한글 표기 블록 8개**, **발화 음절 8개**, **가창 슬롯 8개** 중 무엇인지 문맥에서 구분한다. 결과가 달라지는 모호함만 확인한다. 자료가 일부뿐이면 확인 가능한 구간을 먼저 처리하고 나머지를 미확인으로 남긴다.

## 2. 음악을 고정하고 말을 대응시킨다

| 단계 | 실행 | 다음 단계로 가기 전 점검 |
|---|---|---|
| 음악 조건 보존 | 구간·슬롯 순서, 확인된 쉼·시작 시점·길이, 붙임줄과 멜리스마를 기록한다 | 음표 하나를 무조건 새 음절 하나로 세지 않았는가 |
| 의미 단위 지정 | 주체·행동·대상·시간과 반드시 보존할 표현을 묶는다 | 조사를 떼거나 구절을 옮길 때 뜻이 흐려지는 위치가 보이는가 |
| 발음 대응 | 의도한 읽기와 축약을 정하고 각 발화 음절을 가창 슬롯에 대응한다 | 숫자·외국어·약어의 읽기가 미정인데 빈칸을 채우지 않았는가 |
| 국소 수정 | 충돌하는 구절에 필요한 편집만 적용한다 | 고정 문구나 다른 구간까지 불필요하게 바꾸지 않았는가 |
| 재점검 | 수치, 의미, 말투, 발음 연결, 쉼과 지속 구간을 다시 대조한다 | 수정으로 다른 제약을 깨거나 새로운 발음 충돌을 만들지 않았는가 |

붙임줄로 이어진 같은 음의 지속을 별도 발화로 나누지 않는다. 한 음절에 여러 음표를 배정한 멜리스마도 여러 음절로 바꾸지 않는다. 사용자가 음악 수정까지 허용하지 않았다면 가사를 맞추기 위해 쉼이나 음표를 임의로 삭제하지 않는다.

정밀 대응이 필요하면 `구간·슬롯 | 시작·길이·쉼 | 가사 범위 | 의도한 읽기 | 대응·문제 | 수정` 표를 쓴다. 제공되지 않은 칸은 비워 두거나 미확인으로 표시한다. 단순한 행 길이 교정에는 이 표를 생략한다.

다음 지점은 실제 음악과 함께 검토한다.

- 큰 쉼이 단어 내부나 의미가 아직 성립하지 않은 지점을 끊는가? 의도적인 걸침이면 효과와 이해 가능성을 함께 본다.
- 긴 음·강한 악센트의 조사나 어미가 필요한 초점인가, 우연히 남은 결과인가?
- 빠른 연속 구절에서 자음 전환과 단어 경계가 전달되는가? 받침이 많다는 이유만으로 전부 순화하지 않는다.
- 지속음의 발음이 해당 음역·가창자에게 가능한가? 텍스트만으로 모음의 우열이나 가창 편의성을 확정하지 않는다.

## 3. 문제에 맞는 편집 수단을 고른다

먼저 고칠 행의 주체·대상·행동을 주변 가사에서 짚는다. 한 단어가 사람과 사물 등 여러 대상을 가리킬 수 있다면, 의도한 장면을 고를 단서가 있는지 본다. 장면을 이해할 수 없는 것이 문제라면 필요한 대상을 드러내는 수정이 먼저다. 길이·음절이 줄어도 원래 문제가 남으면 해결한 것으로 평가하지 않는다. 반대로 감정이나 결말을 열어 두는 의도적인 여백은 설명으로 채우지 않는다.

| 편집 | 주로 바꾸는 것 | 적합한 문제 | 남길 검토 |
|---|---|---|---|
| 도치 | 제시 순서·초점·구절 배치 | 핵심어가 늦게 나오거나 다른 위치가 필요함 | 단어·조사를 보존하면 총 표기 음절 수는 같지만 어감과 초점은 달라짐 |
| 축약 | 길이·구어성 | 뜻을 크게 덜지 않고 짧게 말해야 함 | 친밀도·말투·분절이 바뀌며 모든 축약이 그 화자에게 자연스럽지는 않음 |
| 생략 | 길이·정보 밀도 | 맥락에서 회복되는 말이 중복됨 | 주체·시간·대조·인과를 청자가 실제로 복원할 수 있는지 확인 |
| 치환 | 길이·소리·뉘앙스 | 발음 충돌이나 음절 초과가 특정 어휘에 집중됨 | 비슷한 뜻도 행동의 강도·이미지·시제가 달라질 수 있음 |
| 행갈이·프레이징 | 호흡·기대·국소 분포 | 총길이는 맞지만 구절 경계가 충돌함 | 문장 총음절을 줄인 것으로 설명하지 않고 의미 연결·쉼을 다시 확인 |

여러 수단을 썼으면 복합 편집으로 구분한다. 한 대안이 모든 조건을 만족하지 못하면 **어떤 조건을 지킨 안인지** 밝힌다. 원문 유지, 단어 치환, 구절 재배치 중 손실이 가장 작은 선택을 비교하며 정해진 수의 대안을 억지로 만들지 않는다.

교정 결과는 필요한 범위에서 `문제 위치 → 수정안 → 편집 유형 → 얻은 효과와 잃은 의미·어감 → 남은 검증`으로 전달한다. 요구가 가사만이면 설명을 생략하되 불가능한 제약을 충족했다고 말하지 않는다.

## 4. 미니 사례: 같은 뜻, 다른 길이와 분절

아래 수치는 [표기 음절 검사기](../scripts/lyric_meter.py)의 한글 블록 수다. 실제 가창 타이밍의 측정값은 아니다.

| 후보 | 블록 수 | 편집과 판단 |
|---|---:|---|
| `내일 나는 화분을 옮겨` | 9 | 시간·화자·대상·행동을 모두 명시한 원형 |
| `화분을 옮겨, 내일 나는` | 9 | 순수 도치. 행동과 대상을 먼저 제시하고 시간·화자를 뒤에 덧붙이는 어감. 담담한 말투가 목표라면 원형이 더 자연스러울 수 있음 |
| `내일 난 화분을 옮겨` | 8 | `나는`을 `난`으로 축약. 주요 정보는 유지하지만 말의 길이와 구어적 질감이 바뀜 |
| `내일 나는 화분 옮겨` | 8 | 목적격 조사 생략. 대상을 문맥에서 이해할 수 있지만 문장이 더 생략적인 말투가 됨 |

확인할 분절:

- 원형 `내일 나는 / 화분을 옮겨`는 **4+5**다.
- 도치안 `화분을 옮겨 / 내일 나는`은 **5+4**다. 총길이는 그대로이고 정보 순서가 달라진다.
- 축약안 `내일 난 / 화분을 옮겨`는 **3+5**다.
- 조사 생략안 `내일 나는 / 화분 옮겨`는 **4+4**다.

요청이 단지 표기 8개라면 두 축소안이 모두 수치 조건을 만족한다. **4+4 분절까지 지정했다면** 축약안의 총합만 보고 통과시키지 않는다. 조사 생략안도 말투와 의미가 허용되는지 확인한 뒤 선택한다. `/`는 작업용 구절 경계이며 그 자체로 실제 쉼이나 네 박을 뜻하지 않는다.

모든 글자를 보존하면서 총합을 8개로 줄이라는 조건은 원형 9개와 충돌한다. 도치로 해결했다고 주장하지 말고, 글자를 보존한 9개 안과 축약·생략을 허용한 8개 안의 차이를 알린다.

## 5. 혼합 언어와 번역·번안

1. 영어·약어·숫자는 의도한 읽기를 먼저 정한다. 원어 발음, 한국어로 읽는 방식, 축약 여부가 달라지면 발화 음절과 라임도 다시 확인한다.
2. 언어를 넘나드는 경계에서 실제 연결 발음과 말의 자연스러움을 검토한다. 철자 길이로 슬롯을 배정하거나 소리를 맞추기 위해 불필요한 외국어를 끼워 넣지 않는다.
3. 영어 구절은 그 구절의 어휘·문장 강세와 음악 악센트의 관계를 본다. 같은 강세 규칙을 한국어에 옮기지 않고, 한국어는 의미 초점·구절 억양·음악 배치를 구분한다.
4. 번역·번안 요청에서는 보존할 의미·어조와 허용된 소리·길이 변화를 정한다. 직역의 정확성과 가창용 재구성의 자연스러움이 충돌하면 변경된 정보를 알린다. 번역 해설은 요청된 경우 가사 밖에 둔다.

검사기의 한글 수치가 맞아도 외국어 발음이나 실제 가창 대응이 확인된 것은 아니다. 수정 후에는 영향받은 읽기·라임·슬롯을 함께 재검토한다.
