# 표현 선택과 수정 도구

표현이 모호하거나 기법을 비교·분석할 때 필요한 부분만 읽는다. 이름을 많이 붙이기보다 **전달하려는 효과, 그 효과를 만드는 문장, 실패한 이유**를 연결한다. 하나의 표현에 여러 장치가 겹칠 수 있지만, 근거 없이 분류를 늘리지 않는다.

직설은 비교의 기준이자 최종 선택이다. 기법을 적용한 문장이 화자의 뜻·말투·소리를 더 잘 살리지 못하면 직설로 돌아간다. 모든 곡에 비유, 서사 변화, 반전, 해소가 필요한 것은 아니다.

## 이미지와 의미

| 선택 | 적용과 기대 효과 | 실패 신호와 수정 |
|---|---|---|
| 비유: 은유·직유 | 대상과 비교 대상이 공유하는 성질을 먼저 고른다. 은유는 두 대상을 겹쳐 인식하게 하고, 직유는 비교 관계를 드러내며 차이도 남긴다 | 연결점이 설명에만 있거나 비교 대상의 성질이 앞뒤에서 충돌하면 연결할 성질을 좁힌다. 낯선 명사보다 관계에 맞는 비교를 고른다 |
| 의인 | 사물·공간·관념에 의도나 태도가 느껴지는 행동을 부여해 화자의 관계 맺는 방식을 드러낸다 | 사물이 한 행동이 화자의 감정과 무관하면 단순 장식이다. 인간 행동을 덧씌우기보다 실제로 관찰한 움직임을 살리거나 화자의 행동으로 바꾼다 |
| 감각 이동 | 소리·색·촉감 등 한 감각의 성질을 다른 감각에 옮겨 장면의 정서나 질감을 겹친다 | 감각어만 겹쳐 장면을 떠올리기 어렵다면 감지하는 대상과 상황을 복원한다. 익숙한 감각 표현을 자동으로 참신하다고 평가하지 않는다 |
| 상징 | 구체적인 사물·행동이 맥락 안에서 관계나 가치와 연결되게 한다. 반복할 때는 주변 사건 또는 화자의 태도가 그 의미를 쌓도록 한다 | 사물이 등장했다는 사실만으로 상징이라 부르지 않는다. 독자가 읽어낼 연결 근거가 없으면 맥락을 보강하거나 단순 소품으로 둔다. 반드시 반복해야 하는 것도 아니다 |
| 상황·사물의 배열 | 감정명을 직접 말하는 대신 사물·사건·행동의 관계로 정서를 추론하게 한다. 객관적 상관물로 설명할 때도 무엇의 배열이 어떤 정서를 일으키는지 근거를 든다 | 사물 하나가 있다는 이유만으로 감정이 전달됐다고 보지 않는다. 배열의 관계를 보강하거나 필요한 직접 진술을 남긴다 |
| 환유 | 대상과 가까이 연결된 장소·도구·흔적 등으로 대상을 가리켜 설명을 압축하고 시선을 특정 지점에 둔다 | 무엇을 대신 가리키는지 불분명하면 관련 행동이나 주체를 보탠다. 비슷한 성질에 의한 비교라면 비유의 관점으로 다시 본다 |
| 제유 | 부분으로 전체를, 또는 전체로 부분을 가리켜 인물·집단·상황에서 주목할 요소를 고른다 | 지칭 범위가 바뀌며 원치 않는 일반화가 생기면 범위를 좁힌다. 단지 관련된 대상의 교체라면 환유로 설명하는 편이 정확하다. 두 범주의 관계에는 분류 관점 차이가 있을 수 있다 |
| 과장 | 거리·기간·빈도·규모를 실제보다 크게 잡아 화자가 느끼는 강도를 드러낸다 | 숫자와 수식만 커지고 상황이 사라지면 화자의 구체적인 행동을 남긴다. 과장의 크기가 곡의 말투를 깨면 규모를 낮춘다 |
| 축소 | 큰 사건에 작은 표현을 대응시켜 참음·체념·유머 등 말과 상황의 간격을 만든다 | 앞뒤 상황이 없어 감정까지 작아 보인다면 감정을 설명하기보다 사건의 흔적을 보탠다. 필요한 고백을 회피하는 결과라면 직접 말하게 한다 |

비유의 연결을 점검할 때는 **무엇과 무엇을, 어떤 성질 때문에 연결했는가**를 평문으로 풀어 본다. 설명은 편집 판단에 쓰고 완성 가사에 자동으로 덧붙이지 않는다. 의미가 여러 방향으로 열리는 표현도 가능하지만, 아무 해석이나 붙일 수 있다는 이유로 좋다고 판단하지 않는다.

## 문장과 정서

| 선택 | 적용과 기대 효과 | 실패 신호와 수정 |
|---|---|---|
| 대구 | 문장 틀을 나란히 두고 주체·행동·핵심어를 달리해 공통점이나 차이가 들리게 한다 | 문법 틀만 같고 비교할 내용이 없으면 핵심어를 조정한다. 모든 행을 같은 길이로 만들다가 말투가 굳으면 필요한 위치에만 남긴다 |
| 수구·말미 반복 | 행의 처음을 반복해 다음 말을 기다리게 하거나, 끝을 반복해 같은 말로 돌아오는 느낌을 만든다 | 반복 위치가 핵심어를 가리면 앞뒤 위치나 주변 길이를 바꾼다. 동일 어휘 반복의 효과를 별개의 라임 성과로 중복 평가하지 않는다 |
| 행걸침 | 문법적으로 이어지는 말을 행 경계 너머에 배치해 기대·유예·뒤늦은 결합을 만든다 | 행 끝에서 잘못된 뜻으로 닫히면 경계를 옮기거나 단서를 남긴다. 텍스트 행갈이와 실제 음악의 쉼은 다르므로 가창 경계는 음악과 대조한다 |
| 열거 | 서로 관계있는 항목을 골라 장면·범위·집착의 밀도를 만든다. 배열 순서는 공간, 시간, 중요도, 연상 중 목적에 맞게 정한다 | 명사만 늘고 관계가 안 보이면 묶는 기준을 정하고 약한 항목을 덜어낸다. 항목 수 자체를 성과로 보지 않는다 |
| 점층 | 행동의 위험·거리·감정의 노출 등 한 축을 따라 강도를 단계적으로 바꾼다 | 강한 형용사만 쌓이거나 단계가 비슷하면 행동의 차이를 만든다. 고조가 필요 없는 곡이라면 일정한 강도나 하강을 선택한다 |
| 대조 | 같은 기준 위에 다른 상태·선택·시간을 놓아 간격을 드러낸다 | 서로 관계없는 반대말을 붙였으면 비교 기준을 맞춘다. 인물의 우열이나 비하로 흐르면 행동·상태의 차이에 집중한다 |
| 설의 | 답을 구하는 형식으로 화자의 주장·망설임·자기설득을 드러낸다 | 실제 정보가 필요한 질문인지 먼저 구별한다. 답이 정해진 질문을 반복해 감정을 몰아붙인다면 단정이나 행동으로 일부 바꾼다 |
| 돈호·호소 | 부재한 대상, 사물, 관념 등을 듣는 상대처럼 불러 화자의 주의를 그곳에 모은다 | 누구에게 왜 말을 거는지 읽히지 않으면 대상과 관계를 보완한다. 매 행 같은 대상을 불러 진행을 막으면 호출을 줄이고 말하려던 내용으로 들어간다 |
| 감탄·영탄 | 감탄사나 짧은 탄식으로 문장의 속도를 바꾸고 감정이 새어 나오는 순간을 만든다 | 감탄사만으로 정서를 지시하면 직전 상황이나 직후 행동을 보강한다. 모든 행이 절정이면 덜어내고 대비를 남긴다 |
| 모순어법 | 충돌하는 의미를 가까운 말 묶음 안에 두어 동시에 느끼는 상태를 압축한다 | 반대말 결합에 그치면 두 성질이 함께 성립하는 상황을 마련한다. 충돌이 목적이 아니라 오해라면 한쪽 말을 바꾼다 |
| 역설 | 겉으로 모순되는 진술이나 관계가 어떤 조건에서는 성립하도록 만들어 관점을 바꾼다 | 문장만 뒤집었을 뿐 성립 조건이 없으면 화자의 선택이나 사건으로 근거를 보탠다. 풀어도 뜻이 성립하지 않으면 다른 진술을 고른다 |
| 반어 | 표면의 말과 맥락이 가리키는 뜻 사이에 간격을 둔다. 주변 행동·상황·말투가 그 간격을 읽게 해야 한다 | 한 문장을 떼어 놓고 반대 뜻을 가정하지 않는다. 자기기만·허세·거짓말과의 구분이 어려우면 가능한 해석으로 제시한다. 청자가 필요한 단서를 못 얻으면 맥락을 보완한다 |

### 헷갈릴 때 비교할 것

- **반복과 대구:** 같은 말의 재등장인지, 비슷한 문장 틀에 다른 내용을 넣었는지 구분한다. 둘을 함께 쓸 수도 있다.
- **열거와 점층:** 여러 항목이 있다는 것과 강도가 단계적으로 달라진다는 것은 다르다. 실제로 변화하는 축을 확인한다.
- **대조와 모순어법:** 서로 다른 대상의 차이인지, 한 표현 안에서 충돌하는 성질을 함께 붙였는지 확인한다.
- **모순어법과 역설:** 단어 결합의 충돌인지, 진술 전체가 어떤 조건에서 성립하는지 확인한다. 경계가 겹치면 어느 효과를 설명하는지 밝힌다.
- **생략과 불명료함:** 청자가 맥락으로 복원할 수 있는 정보만 덜어낸다. 화자·대상·행동의 관계까지 사라졌다면 필요한 단서부터 되살린다.
- **의도한 모순과 설정 오류:** 화자의 말과 행동이 어긋나 정서가 생기는지, 작사가의 인칭·시간 관리 실수인지 앞뒤 맥락으로 판단한다.

## 시간·시점·응답

| 선택 | 적용과 기대 효과 | 실패 신호와 수정 |
|---|---|---|
| 시간 압축 | 긴 기간에서 관계가 드러나는 행동이나 변화만 골라 짧게 건너뛴다 | 무엇이 변했는지 놓치면 시간 표시보다 변화의 증거를 보탠다. 생략된 사건을 전부 설명해 다시 늘리지 않는다 |
| 순간 확장 | 짧은 순간의 동작·감각·머뭇거림을 나누어 화자가 붙잡고 있는 시간을 느끼게 한다 | 같은 감정을 다른 수식으로 반복할 뿐이면 관찰 대상이나 행동 단계를 달리한다. 확대할 이유가 없으면 압축한다 |
| 시간 교차 | 현재와 과거 등의 장면을 배열해 같은 사물·행동이 달라 보이게 한다 | 청자가 시간 위치를 잃으면 시제·상황·되풀이되는 단서 중 필요한 것만 보탠다. 교차 횟수보다 두 시간의 관계가 드러나는지 본다 |
| 시점 전환 | 말하는 위치나 관찰 대상을 바꿔 같은 사건의 다른 의미를 드러낸다 | 바뀐 화자가 알 수 없는 내면을 사실처럼 말하면 관찰·추측을 구분한다. 화자 변경을 알아야 하는 곡이라면 짧은 단서를 두고, 단순 대명사 교체에 그치지 않는다 |
| 정보 지연 | 뒤에서 알아야 앞부분의 의미가 달라지는 사실을 정하고 공개 시점을 늦춘다 | 처음부터 이해할 필수 상황까지 숨기면 청자가 관계를 잡을 단서를 복원한다. 뒤의 공개가 앞부분과 연결되지 않으면 배치를 바꾸거나 지연을 버린다 |
| 문답·호응 | 질문과 답, 선언과 응답, 리드와 합창 사이에 역할을 나눠 관계나 참여를 만든다 | 응답이 앞말을 그대로 반복할 뿐이면 동의·거절·수정·확인 중 기능을 정한다. 단순 반복이 참여감을 만드는 목적이면 유지한다. 두 화자의 어휘와 지식 범위가 섞이지 않게 한다 |
| 수미상관 | 첫 구절·이미지·구조를 끝에 다시 놓아 닫힘, 순환, 머묾을 느끼게 한다 | 끝의 재등장이 분량만 늘리면 위치나 길이를 바꾼다. 같은 말이 같은 상태로 돌아오는 결말도 허용하며 의미 변화를 억지로 넣지 않는다 |
| 회수 | 앞에 놓은 단서를 뒤에서 다시 쓰며 알아봄, 의미 변화, 연결의 효과를 만든다 | 단서가 너무 약해 알아보기 어렵거나 뒤의 역할이 뜬금없으면 거리·반복량·주변 정보를 조정한다. 처음과 끝에 있어야 하는 것은 아니다 |

시간 압축·확장은 **이야기를 보여주는 밀도**의 선택이다. 가창 속도나 음표 길이가 바뀐다는 뜻이 아니다. 한 화자의 시선이 바뀌는 것, 발화자가 교체되는 것, 과거와 현재를 오가는 것도 각각 구분한다.

## 효과에 맞춰 남기기

아래는 조합 후보이며 정해진 공식이 아니다.

| 원하는 효과 | 비교할 선택 | 과용했을 때 되돌릴 곳 |
|---|---|---|
| 담담하지만 감정이 남음 | 직접 진술, 축소, 행동의 흔적, 생략 | 관계를 이해할 단서가 충분한지 확인한다 |
| 여러 감정이 동시에 있음 | 대조, 모순어법, 말과 행동의 간격 | 모순을 멋진 말로만 만들지 말고 성립 상황을 확인한다 |
| 함께 부르는 참여감 | 문답, 반복, 대구, 짧은 단정 | 응답이 가능한 길이와 뜻인지 검토한다. 실제 합창 효과는 음악에서 확인한다 |
| 뒤에서 새 의미가 열림 | 정보 지연, 시간 교차, 회수 | 앞부분의 최소 이해와 뒤의 연결 근거를 남긴다 |
| 정지·미해결의 여운 | 수미상관, 일정한 반복, 순간 확장 | 정지를 실패로 보고 사건·깨달음·회복을 억지로 추가하지 않는다 |

각 조합은 화자가 실제로 쓸 말인지, 필요한 뜻을 청자가 얻는지, 수정 전보다 얻는 효과가 큰지 비교해 선택한다. 의도적인 낯섦이나 해석의 여백은 유지할 수 있다.

라임·플로 및 펀치라인과 결합할 때는 [핵심 스킬](../SKILL.md)의 해당 절을 따른다. 표현의 뜻이 성립하지 않는 문제를 소리 대응이나 기법 이름으로 덮지 않는다.
