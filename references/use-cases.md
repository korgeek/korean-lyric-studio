# 작업별 작사 실무

필요한 절만 사용한다. 모든 작업에는 [핵심 지침](../SKILL.md)의 제외 조건, 원문 보존, 검증 범위를 적용한다.

## 1. 브리프를 작업 조건으로 바꾸기

사용자가 이미 준 정보를 먼저 읽고 **작업 범위 / 화자와 대상 / 원하는 효과 / 보존 조건 / 음악 자료 / 출력 형식**을 정리한다. 작업에 없는 조건을 모두 질문하지 않는다.

문자 그대로 고정한 조건, 의미를 보존할 조건, 조정 가능한 취향을 구분한다. 특정 구간에만 정한 행 수·음절 규칙을 다른 구간으로 확장하지 않는다. 창작 가정은 짧게 밝히되 가사만 요청하면 불필요한 설명을 붙이지 않는다. 동시에 지킬 수 없는 조건은 충돌 지점과 최소한의 완화 선택지를 알린다.

## 2. 소재가 없거나 감정어만 있을 때

1. 화자가 원하는 것과 실제로 하는 행동 사이의 차이를 찾는다. 경험을 창작해도 되며 사용자의 실제 경험인 것처럼 말하지 않는다.
2. 사물에서 출발한다면 사용 흔적·무게·소리·촉감·움직임을 관찰하고, 그 사물을 다루는 행동을 적는다. 모든 감각을 채우는 과제로 만들지 않는다.
3. 화자의 관계나 선택을 드러내는 관찰만 남긴다. 사물을 다른 것으로 바꿔도 의미가 같다면 장식일 수 있다.
4. 필요한 경우 직접 진술과 장면 중심 표현을 짧게 비교한다. 감정의 명료함과 청자가 추론해야 할 몫 중 무엇이 늘었는지 판단한다.
5. 요청한 분량의 초안으로 연결한다. 소재 목록이나 질문 단계에서 멈추지 않는다.

반복 모티프는 등장할 때마다 **누가 어떻게 다루는가 / 무엇이 달라지거나 그대로인가**로 계획한다. 기능이 있다면 같은 상태로 돌아와도 된다. 모티프의 개수는 장면을 이해할 수 있는지로 결정한다.

### 수행 사례: 소재에서 미해결 후렴까지

의뢰 조건: 낯선 집에 적응 중인 화자, 작은 화분을 소재로, 1절과 후렴만, 밝은 해결은 원하지 않음.

- 관찰 후보: 흙의 마름, 바닥의 빛, 화분을 옮기는 손. 화자의 적응과 연결되는 행동을 고른다.
- 설계: 1절에서는 자리를 바꾸는 행동, 후렴에서는 아직 정하지 못한 상태를 붙든다. 화분을 돌보는 일과 화자의 적응이 연결될 단서를 남긴다.
- 초안 점검: 화분이 등장했다는 이유만으로 상징이라 부르지 않는다. 화자가 왜 자리를 찾는지 읽히는지 본다.
- 수정 판단: 후렴이 결심으로 끝나면 미해결 요청을 다시 확인한다. 반대로 의미를 너무 숨겼다면 필요한 상황 단서를 복원한다.

이 설계는 작업 과정을 보여주는 예다. 새로운 의뢰에는 그 의뢰의 관계와 행동에서 다시 소재를 고른다.

## 3. 제목·훅·구조만 설계할 때

제목은 중심 행동·질문·이미지·태도 중 곡을 대표하는 것을 고른다. 제목이 후렴에 반드시 등장할 필요는 없다. 여러 제목을 요청하면 같은 뜻의 단어만 바꾸지 말고 청자가 처음 예상할 이야기가 어떻게 다른지 비교한다.

훅 후보는 **의미의 핵심 / 반복할 소리나 문장 틀 / 놓일 구간 / 반복의 역할**로 만든다. 설명을 덜어도 뜻이 남는지, 앞 구간의 정보가 있어야 이해되는지, 반복이 몰입·질문·응답·정지 중 무엇을 만드는지 확인한다. 필요하면 문장형과 소리·응답형을 비교하되 청취 기억도를 보장하지 않는다.

구조 요청에는 `구간 | 전달할 정보 또는 유지할 상태 | 말투·밀도·반복의 대비 | 다음 구간과 연결할 단서 | 고정 조건`을 필요한 만큼 채운다. 가사를 요구하지 않았다면 설계표에서 끝낸다.

| 구간 선택지 | 사용할 수 있는 기능 | 설계할 때의 질문 |
|---|---|---|
| 도입 | 목소리·소리·첫 행동으로 진입 | 시작부터 필요한 정보는 무엇인가? 무가사도 가능한가? |
| 벌스 | 관찰·사건·관계·화자의 논리 | 후렴을 어떻게 다르게 듣게 하는가? 같은 상태를 유지할 이유가 있는가? |
| 프리코러스 | 질문·압축·긴장 또는 잠깐의 정지 | 후렴 진입 전에 말의 길이·밀도·기대를 어떻게 바꿀까? |
| 후렴 | 중심 발화·반복·응답 | 전곡에서 반복해 붙들 이유가 무엇인가? |
| 포스트코러스 | 소리·짧은 응답·잔여 에너지 | 앞 후렴과 다른 역할이 있는가? |
| 브리지·대조 구간 | 시간·화자·질감·해석의 변경 | 반전 없이도 대비가 생기는가? 이 구간을 빼면 무엇이 사라지는가? |
| 마지막 반복·아웃트로 | 유지·변주·회수·미해결 여운 | 바꿀 말과 그대로 둘 말을 왜 선택했는가? |

이는 순서나 필수 구성요소가 아니다. 곡이 요구하지 않는 구간을 끼워 넣지 않는다. 후렴을 고음, 프리코러스를 상승으로 확정하려면 실제 음악 근거가 필요하다.

### 수행 사례: 같은 말의 반복을 결정하기

의뢰 조건: 답을 정하지 못한 화자의 후렴을 반복하고, 2절은 그 상태를 유지하되 청자가 더 이해하게 만들기.

- 1절은 선택 직전의 행동, 2절은 결정을 늦추는 구체적 사정으로 설계할 수 있다.
- 후렴 문장을 그대로 두면 상태의 지속이 강조된다. 한 동사만 바꾸면 선택이 시작됐다는 뜻이 생길 수 있다.
- 사용자가 미해결을 원하면 변화가 있는 안을 자동으로 채택하지 않는다. 같은 말을 유지하더라도 주변 장면이 이해를 더하는지 확인한다.
- 문답형이라면 발화자의 역할을 정한다. 실제 두 사람, 한 사람의 자문자답, 합창의 응답을 구별한다.

## 4. 장르를 편집 선택으로 바꾸기

| 요청된 방향 | 먼저 비교할 선택 | 과용 신호 |
|---|---|---|
| 발라드 | 문장의 호흡, 고백의 명료함, 장면과 여백 | 감정을 중복 설명하거나 도치로 말투가 굳음 |
| 인디·포크 | 생활어의 시선, 구체적 행동, 비정형 구절의 자연스러움 | 낯선 사물만 늘고 화자의 필요가 사라짐 |
| 힙합 | 내부운·다음절 대응, 전환어의 위치, 밀도와 쉼 | 소리 때문에 논리·문법이 무너짐 |
| 댄스·팝 | 반복되는 말의 리듬, 응답, 구간 대비 | 짧은 구호만 있고 곡의 태도가 읽히지 않음 |
| R&B | 어절 단위의 여유, 구어성, 미세한 반복 변주 | 음악 자료 없이 늘임·멜리스마를 확정함 |

장르는 출발점이며 규칙이 아니다. 사용자가 요구한 특성이 표와 다르면 사용자의 목표에 맞춘다. 장르 전환에서도 고정한 화자·사건·문구는 보존한다.

## 5. 표현 분석·작사법 학습

분석은 **행의 근거 → 가능한 장치 → 어떻게 작동하는가 → 청각·정서 효과 → 다른 해석 또는 한계** 순으로 한다. 장치가 없으면 없다고 말한다. 분석만 요청했을 때 전체 가사를 고치지 않는다.

학습은 [표현 도구](expression-toolkit.md)에서 필요한 기법만 골라 다음처럼 진행한다.

1. 서로 헷갈리는 개념의 차이를 설명한다.
2. 같은 상황과 의도를 가진 짧은 예시를 새로 만들어 적용 전후를 비교한다. 한 번에 여러 기법을 바꿔 효과의 원인을 흐리지 않는다.
3. 무엇을 더 또렷하게 하고 무엇을 덜 말하게 됐는지 설명한다. 기법을 적용하지 않은 안도 좋은 선택일 수 있다.
4. 같은 목적의 짧은 연습을 주고, 사용자의 시도에는 작동한 부분과 가장 영향이 큰 수정 하나를 피드백한다. 사용자가 응용까지 요청했다면 예시 제공 단계에서 멈추지 않는다.

## 6. 교정·비평·점수

부분 수정은 [멜로디와 편집](melody-and-editing.md)의 수단 비교를 사용한다. 금지 요소가 없는 원문을 비교할 때는 `위치 | 보존 조건 | 수정안 | 편집 수단 | 개선 효과 | 잃는 의미·소리 | 재검사` 중 필요한 열만 보여준다. 가사만 요청하면 표를 생략한다.

문제를 다음과 같이 구분해 수정 순서를 정한다.

- **명시 조건 위반:** 범위·고정 문구·음절·제외 조건 등 실제로 어긴 조건.
- **전달을 방해하는 문제:** 의도하지 않은 인칭·시점 충돌, 뜻을 파악할 수 없는 연결, 자료로 확인된 슬롯 충돌.
- **효과 개선:** 목적에 비해 약한 훅, 흐름을 가리는 표현, 효과 없는 중복.
- **취향 차이:** 직설과 여백, 조밀함과 간결함, 반복 횟수 등 여러 해법이 성립하는 선택.

비평 요청에 점수나 전체 개작을 자동으로 붙이지 않는다. 점수를 요청하면 목표에 필요한 평가 축과 배점을 정하고 각 점수에 실제 구절의 근거를 붙인다. 항목별 `0~5`를 쓴다면 `항목 배점 × 항목 점수 / 5`로 환산할 수 있다. 실제 가창을 평가할 자료가 없으면 **미평가**로 두고, 100점 환산 요청 시 평가 가능한 항목만으로 배점을 다시 합계 100으로 정해 텍스트 평가라고 밝힌다. 누락된 가창을 0점이나 추정 점수로 채우지 않는다.

## 7. 음악 생성 도구용 전달

1. 요청한 가사와 구간만 복사 가능한 블록으로 정리한다. 제목·번역·해설이 노래될 본문에 섞이지 않게 한다.
2. 스타일 지시를 요청받았다면 장르·분위기·편곡 정보를 별도 블록에 둔다. 사용자 지정값과 새로 제안한 선택을 구별한다. 요청하지 않은 보컬 특성·악기·속도를 필수 사양으로 고정하지 않는다.
3. 일반적인 구간 표기는 텍스트 구분으로 사용한다. 특정 서비스의 전용 문법이나 동작이 필요하면 그 시점의 공식 지원 범위를 확인하고, 확인할 수 없으면 호환성 미확인으로 남긴다.
4. 작업용 `/`, `|`, 색상·라임 라벨, 음절 수, 대안과 검수 메모를 최종 가사에 무심코 섞지 않는다. 사용자가 유지하도록 지정한 기호는 의도를 확인해 보존한다.

가사·스타일 지시·번역을 작성한 사실과 실제 음원 생성·청취 검증을 구분한다.
