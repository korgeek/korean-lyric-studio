# 행동 검증 기준

아래는 테스트의 기대 동작이며 실제 실행·통과 기록이 아니다.

창작 동작은 새로운 주제의 자연스러운 한국어 가사로 확인한다. 라임의 대응 범위, 의미 전환, 화자의 일관성, 수정으로 나아진 효과를 실제 구절에서 설명할 수 있어야 한다. 표기 음절 검사 통과나 기법 개수로 창작 품질 검증을 대신하지 않는다.

| 작업 조건 | 점검할 것 | 기대하는 수정 판단 |
|---|---|---|
| 화자·관계·말투를 지정한 창작 | 그 화자가 지금 할 말인지, 초안이 요청한 범위를 지키는지 | 어울리지 않는 어휘를 고치고 초안 뒤 짧은 비평과 대안 제시 |
| 추상적인 감정을 구체화 | 행동과 관찰이 관계를 드러내는지 | 기능 없는 소품을 덜고 감정을 전달하는 행동에 집중 |
| 직접 진술과 여백 중 선택 | 감정의 명료함과 추론에 필요한 정보가 남는지 | 직설을 무조건 비유로 바꾸지 않고 목적에 맞는 안 선택 |
| 미해결 반복과 가사만 출력 | 반복이 맴돎·몰입 등 의도한 기능을 하는지 | 기능이 있으면 유지하고 해설이나 해소 결말을 덧붙이지 않음 |
| 다의어 펀치라인 | 두 뜻이 각각 문맥에서 자연스럽게 성립하는지 | 억지 의미를 제거하거나 다른 전환 지점 선택 |
| 후행 재해석 | 뒤 구절이 앞말의 대상·범위·의도를 바꾸는지 | 필요한 단서를 남기고 전환을 미리 설명하는 말과 후속 해설 축소 |
| 앞 구절의 단서 회수 | 재등장한 말·행동·사물의 역할이 달라지는지 | 연결이 약하면 단서를 보강하고 단순 중복이면 덜어냄 |
| 라임과 발음 조정 | 실제 소리가 이어지며 어순·조사·뜻이 자연스러운지 | 운을 위한 비문을 고치고 근사운이나 다른 배치 비교 |
| 다음절 라임과 내부운 설계 | 의도한 발음의 모음 흐름·받침·음절 경계와 반복 위치가 대응하는지 | 철자만 닮은 후보를 바꾸고 부분 일치를 완전한 일치로 평가하지 않음 |
| 라임 유형 분류 | 각운·내부운은 위치, 다음절은 대응 범위라는 기준을 구분하는지 | 한 구절에 위치 분류와 범위 분류를 함께 붙이고 서로 배타적인 유형으로 처리하지 않음 |
| A/B 라임 그룹 표시 | 의도한 발음·모음열·대응 음절 경계가 일관되고 차이를 기록하는지 | 반모음·음질 차이를 숨기지 않고 근거에 따라 그룹을 조정하며 완전운으로 과장하지 않음 |
| 여러 발음이 가능한 모음을 포함한 비교 | 실제 읽기가 주어졌는지, 선택한 발음의 가정을 밝혔는지 | 가능한 읽기에 따라 달라지는 소리 차이를 구분하고 표기만으로 반모음 유무를 확정하지 않음 |
| 동일 어휘와 어미의 반복 | 반복 효과와 서로 다른 어구의 라임을 구분하는지 | 반복은 기능에 따라 유지하되 독립적인 라임 설계의 성과로 중복 계산하지 않음 |
| 색상과 네 칸 격자로 라임 분석 | 비트 자료가 있는지, 색과 함께 문자 라벨을 제공하는지 | 비트가 없으면 텍스트 분석으로 표시하고 네 칸을 자동으로 네 박에 대응시키지 않음 |
| 여러 행에 걸친 라임 연결 | 소리의 반복이 의미 전개와 이어지고 밀도에 대비가 있는지 | 같은 어미만 나열하거나 뜻이 끊기면 핵심 어휘·운의 위치를 바꾸고 여백 확보 |
| 라임 단어를 유지한 뒤 문장이 어색해짐 | 주체·동작·목적어·수식 관계를 해설 없이 복원할 수 있는지 | 운을 위해 붙인 명사구나 의도하지 않은 의인을 고치고 필요하면 라임 어휘군 재선택 |
| 라임과 의미 전환 결합 | 전환어가 소리와 문맥에서 모두 성립하고 필요한 앞 단서가 남는지 | 라임에 맞춘 억지 의미를 버리거나 전환어·어순을 함께 다시 설계 |
| 빠르고 조밀한 구절 | 단어 경계·호흡·전환어의 전달이 가능한지, 실제 비트·가창 자료가 있는지 | 주변 음절을 덜거나 구절을 나누며 자료 없이 특정 속도·박 배치가 검증됐다고 하지 않음 |
| 문자 보존과 음절 축소를 동시 요구 | 제약을 함께 충족할 수 있는지 | 충돌을 밝히고 도치와 생략·치환의 결과를 구분 |
| 박자·속도만으로 멜로디 적합성 요구 | 음표·쉼·가창 슬롯을 확인할 자료가 있는지 | 텍스트 점검과 실제 음악 검증을 분리하고 없는 분석을 주장하지 않음 |
| 한글·로마자·숫자 혼합 행 | 표기 블록 수와 의도한 발음의 차이 | 읽는 방식의 가정을 밝히고 실제 가창 수치로 확정하지 않음 |
| 의미·고정 구절 보존을 요구하는 퇴고 | 수정이 의도·말투·이미지에 미치는 변화와 필수 제외 조건의 충돌 | 허용된 보존 조건을 지키고 대안의 이득과 손실을 설명하며 원문 유지도 허용 |
| 뜻을 두 가지로 읽을 수 있는 구절의 명료화 | 의도한 여백인지, 대상·행동을 잘못 이해하게 하는 혼동인지 | 필요한 정보만 남겨 해결하고 수정 후 같은 혼동이 남는지 다시 확인. 길이 감소만으로 개선 판정하지 않음 |
| 자체 비평 뒤 수정 대안 제시 | 지적한 원인과 수정으로 달라진 요소가 연결되는지 | 다른 장점이 생긴 것과 해당 문제를 해결한 것을 구분하고, 동일 기준으로 전후를 다시 비교 |
| 강한 자신감과 타격감 있는 표현 | 힘이 자신의 행동·성과·선택에서 나오는지, 타인을 낮추는 방식에 기대는지 | 행동의 구체성·대조·리듬으로 힘을 살리고 인신공격과 비하 제거 |
| 비속어·인신공격·실명·연예인 언급·비하가 포함된 입력 | 가사뿐 아니라 분석·제목·대안·수정 전후 비교에도 금지 요소가 재출력되는지 | 행 번호와 문제 종류로 위치를 설명하고 금지 요소를 인용·음차·마스킹하지 않은 새 표현으로 수정 |
| 주제 없이 소재 발굴부터 요청 | 감각·사용 흔적·행동이 화자의 욕구와 연결되는지 | 소재 목록이나 질문에 머무르지 않고 요청한 초안까지 연결 |
| 제목·훅만 요청 | 후보마다 대표하는 관점이나 소리의 기능이 다른지 | 같은 단어 치환만 반복하지 않고 요청한 범위에서 비교 |
| 구조만 요청, 결말은 미해결 | 구간별 상태·대비·연결 단서를 설계하는지 | 가사 전곡이나 회복 결말을 추가하지 않고 정지·반복의 기능 보존 |
| 표현 기법을 배우고 연습하고 싶음 | 개념 구분·새 예시·효과 비교·실습으로 이어지는지 | 기법 목록만 나열하지 않고 적용 전후의 이득·손실 설명 |
| 반어·역설·모순어법 등 수사 분석만 요청 | 맥락 근거와 표현 단위가 구분되는지 | 없는 기법을 만들어내거나 전곡 개작을 하지 않음 |
| 시간 교차·문답형 구성 | 시간·화자의 전환을 알아볼 단서가 있는지 | 혼동 지점만 보완하고 실명이나 불필요한 설명을 추가하지 않음 |
| 실제로 지정한 슬롯·쉼·한 음절의 여러 음표 | 음표 개수와 가창 음절 슬롯을 구분하고 고정한 쉼·길이를 보존하는지 | 뜻·예상 발음·슬롯을 대응시켜 국소 수정하고 실제 가창은 별도로 남김 |
| 같은 총음절 수, 다른 구절 분할 | 도치·행갈이와 축약·생략을 구분하는지 | 총합뿐 아니라 분절별 분포와 의미 초점 변화를 확인 |
| 혼합 언어 가사와 해석을 요청 | 언어 전환의 의미·말투·발음이 자연스럽고 풀이가 분리되는지 | 알파벳 수를 가창 음절로 세지 않고 번역·뉘앙스·주요 어휘를 가사 밖에 제공 |
| 도구용 가사와 스타일 지시 | 사용자 지정값·제안·미확인 호환성을 구별하는지 | 작업용 라임 라벨·음절 수를 정리하고 가사·스타일을 별도 전달 |
| 음원 없이 100점 평가 요청 | 텍스트 평가 근거와 미평가 항목이 명확한지 | 실제 가창을 0점이나 추정 점수로 채우지 않고 평가 가능한 항목의 배점 합계 확인 |
| 스크립트를 실행할 수 없는 환경 | 창작·학습이 실행 도구에 불필요하게 막히는지 | 짧은 행을 수동 분절하고 수행한 검증만 설명 |
| 일반 산문 교정·작사와 무관한 문학사 질문 | 작사 스킬 적용 범위에 해당하는지 | 작사 모드·가사 형식·음절 규칙을 강제로 적용하지 않음 |

표기 음절 검사기 테스트는 스킬 폴더에서 `python3 -m unittest discover -s tests -v`로 실행한다. 표현과 가창의 효과는 별도로 판단한다.

## 독립 실행용 요청

아래 요청을 새로운 세션에서 스킬과 함께 실행하고 위 기준으로 실제 결과를 검토한다. 문서에 적힌 기대 동작만으로 통과 처리하지 않는다.

1. **소재·구조:** “낯선 동네에 적응하는 인디 곡의 소재를 찾아서 1절과 후렴의 구조만 설계해줘. 밝게 해결하지 말고, 왜 그 소재를 골랐는지도 짧게.”
2. **학습:** “축소와 반어의 차이를 작사 관점에서 설명하고, 같은 상황으로 짧은 예시를 새로 만들어줘. 내가 해볼 연습 하나도 줘.”
3. **편집·슬롯:** “멜로디의 가창 음절 슬롯은 3개, 쉼, 5개야. 뒤 묶음 첫 음절은 두 음표에 걸쳐. ‘내일 나는 화분을 옮겨’를 시간과 행동은 유지해서 맞춰줘. 변경 수단과 의미 손실을 설명해줘.”
4. **반복·장르:** “결정을 계속 미루는 화자의 힙합 후렴 4행을 써줘. 반복과 내부운을 쓰되 타인을 낮추지 말고 마지막에도 답을 정하지 마. 짧은 비평과 한 곳의 수정 대안도 줘.”
5. **형식·해석:** “한국어 벌스 2행과 짧은 영어 응답 1행을 음악 생성 도구에 넣을 형식으로 써줘. 주제는 새 출발, 담담한 팝이야. 영어 뜻·뉘앙스와 스타일 지시는 가사와 분리해줘.”

설치 폴더의 `SKILL.md`에서 연결된 가이드를 읽을 수 있는지도 확인한다. 시나리오 통과는 해당 입력에서 관찰한 동작이며 모든 창작 결과의 품질 보장은 아니다.

## 장르별 창작과 후속 퇴고

새로운 상황으로 아래 작업을 독립 실행한다. 실제 의뢰의 장르·분량·고정 조건을 먼저 정하고, 응답을 보존한 뒤 결과의 구절을 근거로 평가한다.

| 작업 | 초안에서 볼 것 | 후속 퇴고에서 볼 것 |
|---|---|---|
| 발라드 | 화자와 관계가 행동으로 드러나는가, 후렴의 중심 발화가 곡을 묶는가, 자연스러운 구절 길이인가 | 지정한 후렴 일부를 줄여도 고정 문구와 다정함·거리감이 유지되는가 |
| 인디 | 생활어의 시선과 작은 관찰이 납득되는가, 여백과 정보 부족을 구분하는가, 요청하지 않은 교훈을 붙이지 않는가 | 모호한 대상·행동을 고치면서 유머와 다른 행의 장점을 보존하는가 |
| 힙합 | 실제 발음에서 라임의 범위와 차이가 확인되는가, 문법·논리가 소리 때문에 무너지지 않는가, 펀치라인이 앞말의 이해를 바꾸는가 | 약한 구절을 바꿔도 앞뒤 의미와 유지할 라임·전환이 성립하는가 |

초안의 자체 비평도 검토한다. 작법의 의도를 설명했다는 이유로 실제 효과까지 성공했다고 판정하지 않는다. 가사만 읽은 판단과 해설을 읽은 판단이 다르면 부족한 단서를 찾는다.

후속 요청에는 문제와 보존 범위를 주고 수정 문장 자체를 정답으로 제공하지 않는다. 수정 전후의 지정 밖 행·고정 문구·행 수를 대조하고, 의미·소리의 이득과 손실은 구절로 설명한다. 약점 때문에 지침을 고쳤다면 다른 소재의 새 의뢰에서도 확인한다. 지침에는 재사용할 판단 기준을 남기고 특정 시험의 정답 문구를 넣지 않는다.
